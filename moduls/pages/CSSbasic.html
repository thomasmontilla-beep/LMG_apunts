CSS es un lenguaje de estilos que controla la presentación y el diseño de los documentos web escritos con HTML, funciona con una metodologia de cascada, lo que significa que lo nuevo sobreescribe los nuevos estilos. y los buscadores siempre buscaran los estilos mas especificados.

.parrafo {
...
}

.article .parrafo {
...
}

Tambien funciona con herencias, es decir, que los nuevos estilos heredan los antiguos dependiendo de como esten

estilos de aplicación

Pequeñas partes del CSS se pueden aplicar directamente a una etiqueta del HTML, como:

<p style="color: red; font-size 20px;">A este texto </p>

aunque es una aplicación rapida y directa a un texto, no se puede reutilizar y requiere cambiar manualmente cada linea en caso de algun cambio.

Un CSS incrustado, se puede agregar dentro de la etiqueta <Style> en la sección <head> del HTML, aunque es puede llegar a ser mas eficiente, solo es aplicable para una sola pagina.

Y finalmente una hoja de estilos externa (stylesheets), es un enlace separado del HTML que almacena un archivo unico de CSS, y aunque en el caso de que el archivo CSS tenga algun inconveniente, los estilos se puden reutilar en diversas paginas, facilita la separación de contenidos.

¿Como funciona CSS?

CSS tiene una sintaxis basica, en la cual se indica un elemento dentro del HTML al cual se le quiera agregar un estilo y, luego dentro se le agregan las propiedades.

p {
color; red
background-color;green
width; 100%
}

primero esta para seleccionar etiquetas como "h1", "P", "article" etc..., el cual aplicara a todas las etiquetas de la pagina, luego estan las clases, que se seleccionan con .class en el CSS, y se asignan con el atributo class en HTML.

Luego con los id's, los cuales se asignan y funcionan igual que las clases, aunque no se pude usar para varios elementos, solo uno.

Y finalmente los indicadores universales, funcionan colocando un *, y normalmente se utilizan al unicio del css para agregar un margen y padding 0.

* {
margin: 0;
padding: 0;
}
