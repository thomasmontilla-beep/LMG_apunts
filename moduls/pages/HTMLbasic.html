Introdución al HTML

HTML = HyperText Markup Language

El HTML es un lenguaje de marcas para crear paginas web, hoy en dia es el lenguaje estandarizado para las paginas web, es decir que casi todas las webs de internet por no decir todas, usan html como parte de su estructura. pues

Etiquetas basicas

HTML funciona con etiquetas las cuales se abren con <inicio> y cierran con equiquetas como <inicio> , es importante saber que no se cambia el nombre solo se agrega una barra. Tambien hay que tener en cuenta que hay etiquetas que no necesitan ser cerradas, aunque son casos ecepcionales como "br", "hr, "img" y otras mas.

Etiquetas para titulos.

Las etiquetas para titulos dentro del HTML son las "H1" - "H2" ... hasta la "H6", cada una cuenta con su propio tamaño, y es importante que en una misma pagina no puden haber mas de un solo H1, por eso aqui hay un ejemplo visual de como funciona cada una de estas etiquetas.

Etiquetas de estructura.

Las etiquetas de estructura mas basicas con la <p>, la cual es usada para crear y separar entre si, parrafos de texto. entre otras etiquetas tambien esta la <br> la cual funciona como un enter.

Etiquetas de formato para el texto

Estas etiquetas agregan un formato al texto, como <strong> para agregar negrita y una importancia al texto, <b> que tambien aplica negrita pero sin importancia al texto, esto se hace mas por estructura de la pagnia web, para que sea recomendada por google.

Atributos de las etiquetas

Aciertas etiquetas se les puede dar atributos, elementos que modifican el texto como:

  • <a id="identificador">
  • <a class="clase">
  • <a style="color: blue: text-align: center;">
  • <a titol="titol adicional">
  • <a href="URL">
  • <img src="ruta fuente">

Tablas

Las tablas se estructuran principalmente por las etiquetas:

  • <table> Es lo que define que es una tabla, el contenedor principal.
  • <tr> Es lo que define las filas.
  • <td> Crea una celda dentro de una fila.

La tabla se veria mas o menos asi:

Maria 26
Jose 26
Maricarmen 26

Algunos de los atributos son "border" el cual agrega un borde alrededor de la tabla y las celdas, "cellpading" que agrega un espacio entre el contenido entre celda y celda, y "cellspacing" que controla el espacio entre las celdas de la tabla.

Tambien hay otras etiquetas usadas para las tablas como:

  • <thead> Define el encabezado de la tabla.
  • <tbody> Agrupa el cuerpo de la tabla, en filas.
  • <th> Se utiliza para crear una celda, por defecto, centrada y en negrita.
