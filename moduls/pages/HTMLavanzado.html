Etiquetes avanzadas

Inicio HTML basico

Con la evolución del HTML5, se introducen muchas nuevas etiquetas con otras funcionalidades, para poder gestionar mejor el contenido, y facilitar la experiencia del usuario. Como la etiqueta <nav> que se utiliza para las barras de navegación, como en esta pagina.

Etiquetas basicas de HTML5

Aunque tambien hay otras etiquetas como <aside> la cual es usada para barras laterales, o anuncios, no muestra un cambio visible, solo funciona como estructura de la pagina para el navegador.

La etiqueta <article>, es usada para la definicion de bloques de contenidos autonomos dentro de una pagina, es decir como estos mismos parrafos de texto, que son explicaciones breves de las etiquetas.

La etiqueta <section>, se usa para agrupar el contenido relacionado dentro de una pagina, es decir como varios parrafos que hablan sobre lo mismo.

Y aunque por si solos, realmente no tienen cambios visibles tanto el <article> y <section>, sirven como una forma de organizar mejor el codigo tanto para facilitar la implementación de estilos como el CSS.

tambien existen etiquetas encargadas de agrupar los elementos multimedia (imagenes y videos) y sus descripciones con etiquetas como <figure> y <figcaption>.

Y luego hay etiquetas como <header> y <footer> las cuales al igual que el section y article, solo ayudan a definir el encabezado y pie de pagina de la web.
